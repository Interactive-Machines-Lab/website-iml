## Summary

Industrial robots are hard to program without specialist training, which keeps them out of reach for many designers and educators. This paper proposes procedural animation as a more intuitive way to program them: the user describes high-level actions and the system resolves the low-level constraints. A workflow connects the Blender animation environment to robot control through a visual programming language, so robot motion is animated rather than written as toolpaths. Task examples show reduced programming complexity and let novices create adaptable robot motions with little training.
